# 04 — One-line Teach and Recall journey

**What to build:** Turn Practice into the focused LINE/64 loop for one selected line: understand the concept, learn with guidance, recall without it, receive authored correction, save each settled outcome, and bank automatically.

**Blocked by:** 02 — Timed review, preferences, and learner management; 03 — Repertoire discovery and reference Study.

**Status:** ready-for-agent

- [ ] Home Continue, Course Start lesson, and trainable line rows enter a single selected line rather than an entire level.
- [ ] Untouched lines show concept entry, then run Teach followed by Recall.
- [ ] Banked or mastered lines opened directly run Recall without repeating Teach.
- [ ] Queue entry runs Review only for positions currently due.
- [ ] Teach shows the route guide and does not contribute scored accuracy.
- [ ] Recall and Review hide guidance until requested.
- [ ] The board remains the largest element, square, uncropped, centered, and attached to the Eval Bar across supported layouts.
- [ ] All 64 squares remain persistent, accessible real buttons with delegated tap, drag, selection, focus, animation, and cleanup behavior.
- [ ] Only Board and Eval Bar update in place; other visible practice regions follow the existing rendering boundary.
- [ ] Move Animation, Move Beat, Tempo Cut, reduced motion, streaming evaluation, captures, castling, and reply settlement retain existing behavior.
- [ ] Active-practice Settings opens as a modal without discarding the line.
- [ ] Illegal moves give local unscored feedback.
- [ ] A repertoire miss presents the authored “Why this move” explanation, expected move, and retry before secondary engine detail.
- [ ] Move-cost analysis appears in a collapsed Engine note and never blocks retry.
- [ ] Every completed position outcome persists immediately; save failure is visible and retryable.
- [ ] Exiting mid-line leaves the line unbanked while retaining saved position history.
- [ ] Reopening an incomplete line starts that line from its beginning.
- [ ] Successful completion banks automatically without a redundant Bank line action.
- [ ] Practice uses no toast, confetti, streak, badge, glow, gradient, or celebratory animation.
- [ ] Unit and stubbed-browser coverage proves phase selection, one-line scope, authored feedback, immediate persistence, automatic banking, and Board/Eval Bar continuity.
